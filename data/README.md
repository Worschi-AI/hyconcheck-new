# data/

Datenbestände für Benchmark und Ground Truth.

- Jede Datenquelle erhält einen Eintrag mit Herkunft, Lizenz, Abrufdatum, Umfang und Aufbereitungsschritten.
- Rohdaten und Caches (`data/raw/`, `data/cache/`) werden nicht versioniert (siehe `.gitignore`); Annotationen, Schemata und Aufteilungen werden versioniert.
- Keine Übernahme von Daten oder Annotationen aus früheren Repositorys (ADR-0001).
- Personenbezogene Daten werden vor Ablage anonymisiert oder ausgeschlossen.

Derzeit leer; Datenquellen werden in AP3 (BL-020) festgelegt.
