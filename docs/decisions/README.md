# Entscheidungsprotokoll (ADR)

Wesentliche technische und Projektentscheidungen werden nach Master-Prompt §29 festgehalten: Problem, Evidenz, Optionen, Entscheidung, Begründung, Auswirkung, Datum, zugehörige Experimente/Commits. Keine unnötige Bürokratie.

- Dateiname: `ADR-nnnn-kurztitel.md`, fortlaufend nummeriert; Vorlage: [ADR-0000-vorlage.md](ADR-0000-vorlage.md).
- Status: `vorgeschlagen`, `angenommen`, `abgelöst durch ADR-nnnn`, `verworfen`.
- Ein angenommenes ADR wird inhaltlich nicht mehr geändert, sondern durch ein neues ADR abgelöst oder präzisiert (Statusvermerk zulässig).
- Abweichungen vom Forschungsplan (§26) werden hier dokumentiert.
