# Entscheidungen (ADR)

Projekt- und Architekturentscheidungen werden als Architecture Decision Records abgelegt.

- Dateiname: `ADR-nnnn-kurztitel.md`, fortlaufend nummeriert.
- Vorlage: [ADR-0000-vorlage.md](ADR-0000-vorlage.md).
- Status: `vorgeschlagen`, `angenommen`, `abgelöst durch ADR-nnnn`, `verworfen`.
- Ein ADR wird nach Annahme nicht mehr inhaltlich geändert, sondern durch ein neues ADR abgelöst.
