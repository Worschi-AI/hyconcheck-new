# experiments/

Experimentprotokolle. Ein Experiment wird erst durchgeführt, wenn hier ein Protokoll mit folgenden Angaben vorliegt:

- Ziel und Hypothesenbezug (H1–H7)
- Daten (Benchmark-Version, Aufteilung)
- Konfiguration (Verweis auf `configs/`)
- Metriken und Entscheidungskriterien
- Abbruchkriterien
- Ergebnisablage (Verweis auf `results/`)

Derzeit leer; in der Grundlagenphase werden keine Experimente durchgeführt.
