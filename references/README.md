# references/

Quellenregister für Literatur und Stand der Technik nach Master-Prompt §34. Derzeit leer; Ablagestruktur und Rechercheprotokoll werden in BL-001 festgelegt.

## Regeln

- **Themen (§34):** contradiction detection, Natural Language Inference, document-level NLI, cross-document contradiction detection, semantic consistency checking, entity resolution, temporal reasoning, temporal knowledge graphs, status/state transition modeling, fact verification, evidence graphs, knowledge graph reasoning, neuro-symbolic AI, uncertainty calibration, evidence fusion, contradiction benchmarks.
- **Priorität (§34):** 1. peer-reviewed Literatur, 2. etablierte Benchmarks, 3. hochwertige Preprints, 4. offizielle technische Dokumentation, 5. nachvollziehbare Open-Source-Implementierungen.
- Quellen werden mit vollständiger Provenienz gespeichert (Autor, Titel, Venue/Quelle, Jahr, Identifier/URL, Abrufdatum, Screening-Entscheidung, Bewertung).
- Nur tatsächlich geprüfte Quellen werden erfasst; keine Quelle wird behauptet, die nicht geprüft wurde (§23, §34).
- Frühere Arbeiten zu HyConCheck außerhalb dieses Repositorys werden hier – falls erwähnt – ausschließlich als externe Quellen mit Herkunftskennzeichnung behandelt (ADR-0001, ADR-0002).
